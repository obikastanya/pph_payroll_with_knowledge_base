# 07_kasus_uji_resmi — Contoh perhitungan resmi (GT1)

Transkripsi contoh perhitungan yang tercetak di dalam regulasi (PER-16/PJ/2016, PMK 168/2023, PMK 10/2025, PMK 72/2025, PMK 105/2025, PP 58/2023). Angka disalin apa adanya dari dokumen.

- 46 kasus dalam lingkup (pegawai tetap), satu berkas JSON per kasus; 4 kasus di luar lingkup ditranskripsi lengkap (`dalam_lingkup: false`).
- `di_luar_lingkup.json`: 38 contoh di luar lingkup (bukan pegawai tetap), ditranskripsi ringkas.
- `index.csv`: satu baris per kasus (regulasi, bagian, halaman PDF, rezim, skenario, hasil cek aritmetika).

Peran di v2: acuan GT1 untuk validasi KB acuan (`12_emas`). Tidak dibaca oleh *harness*.
