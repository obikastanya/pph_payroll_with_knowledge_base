# Klausul PKB

Satu CSV per PKB di `../dokumen/`: klausul yang memengaruhi upah atau PPh 21, dengan id klausul (misalnya `WIKA-31-3`), pasal, kutipan, rumus, dan pengaruhnya ke bruto, pengurang, atau penanggung pajak.

Peran di v2: rujukan klausul untuk contoh GT5 (`11_acuan/gt5_contoh_kebijakan`; kolom "Klausul PKB" di `review_pakar/uji_perhitungan_pph21.xlsx`).
